# Keyflow

Мобильный веб-тренажёр для занятий на пианино. Приложение показывает MIDI-ноты над полноразмерной клавиатурой, умеет ждать сыгранные ноты, зацикливать фрагмент и фильтровать партии рук.

## Запуск

Открой `index.html` в браузере или запусти локальный сервер:

```powershell
python -m http.server 8000
```

Для микрофона и Web MIDI браузер должен разрешить доступ к устройству. На телефоне открой сайт по HTTPS и разреши микрофон; поддержка MIDI-клавиатур зависит от браузера и подключённого оборудования. Без внешнего инструмента можно потренироваться, нажимая клавиши на экране.

Экранная клавиатура и режим прослушивания MIDI воспроизводят встроенный тембр через Web Audio. Браузер включает звук после первого касания клавиши или нажатия «Начать»; если автозапуск заблокирован, приложение объяснит, как включить звук. Удержание клавиши и длительность MIDI-ноты управляют окончанием звучания.

Импортируй собственный файл `.mid` или `.midi`: приложение не загружает и не содержит ноты или аудио «Drawing Love Reimagined». MIDI-файл читается локально в браузере и не отправляется на сервер. Партии рук определяются по высоте ноты (ниже До4 — левая, До4 и выше — правая); их можно переключать в тренажёре.

## Публикация ссылки

Проект настроен для GitHub Pages. После публикации в GitHub дождись успешного запуска workflow **Deploy piano practice app to GitHub Pages**. Затем открой **Settings → Pages** в репозитории и скопируй выданный HTTPS-адрес сайта — он откроется на телефоне. Микрофон требует HTTPS или `localhost`.
